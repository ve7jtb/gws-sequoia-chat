Local settings

Mail and Chat accounts

Choose the base profile at sign-in. Gmail uses a separate -mail credential profile and requests only Gmail read and send access. Chat keeps its existing session and permissions. Gmail API must be enabled in the OAuth project.

Software identities

Create identities with the standalone CLI or identity helper, in an immediate directory under private/. Their passwords are requested for each operation and are not saved by this interface.

Storage and session

gws stores Google credentials separately using its OS keyring integration. This interface saves public contacts, trust decisions, encrypted outgoing bundles and send receipts. Decrypted text and passwords are held in memory, not intentionally written to disk; OS swap and crash dumps are outside that guarantee.

Clear session disconnects this browser and discards drafts and displayed messages. It does not revoke Google access or delete gws credentials. Quit the launcher to stop the helper. No service worker or offline message cache is installed.
